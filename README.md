# CalculIPv6

Création d'un site web dédié au calcul d'adresses IPv6 (**CalculIPv6**), conçu comme la suite logique du projet CalculIP réalisé à l'IUT. Le site est actuellement en cours de développement et propose une version "Alpha" (0.0.1) comprenant 7 premiers exercices pour apprendre à maîtriser l'IPv6.

## Login utilisateur

Pour l'instant, je vous donne gracieusement un accès (ce qui ne sera probablement plus le cas dans une version ultérieure... quoique, je me dis que le site pourrait être déployé dans des universités et être lié à leur CAS) :

* **Nom d'utilisateur :** `admin`
* **Mot de passe :** `1234`

## Axes d'amélioration pour les futures versions

* **Plus d'exercices !**
* **Une meilleure page d'administration** (avec un CRUD, ce que n'a pas encore la version actuelle).
* **Une refonte du site** par un développeur frontend.
* **Une diffusion sur Internet** et la sécurisation en HTTPS.
* **Une page de profil** qui comptabilise les points au lieu de simplement répertorier les réussites (ou plutôt un système de pourcentage, du genre : *"Vous avez complété 50 %"*).
